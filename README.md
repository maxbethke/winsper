# winsper — Local Windows Meeting Transcriber

A fully local, offline transcription utility for Windows. Drag a Zoom (or
any) recording onto `transcribe.bat` and get a `.txt` transcript next to
it, using [whisper.cpp](https://github.com/ggml-org/whisper.cpp) and
ffmpeg. No cloud APIs, no accounts, no network access at transcription
time.

See `specs/requirements.md` for the full spec this was built against.

## Repo layout

```
winsper/
├── src/                  # source of truth for the shipped scripts
│   ├── transcribe.bat    # drag-and-drop entry point
│   ├── setup.bat         # downloads whisper.cpp/ffmpeg/model on first run
│   └── README.txt        # end-user docs, bundled into the release zip
├── scripts/
│   └── build.sh          # packages src/ into the release zip
├── dist/                 # build output — gitignored, regenerated by build.sh
└── specs/requirements.md
```

The release zip is just these three files — `whisper-cli.exe`,
`ffmpeg.exe`, and the model are **not** bundled; `setup.bat` downloads
them onto the end user's machine the first time they're needed. Always
edit `src/`, never edit inside `dist/`.

## Build / Release

Requires `zip` (standard on macOS/Linux).

```bash
./scripts/build.sh
```

This copies `transcribe.bat`, `setup.bat`, and `README.txt` from `src/`
into `dist/LocalTranscriber/` and zips it to:

```
dist/LocalTranscriber.zip
```

There's nothing to download at build time — the zip is tiny since the
dependencies are fetched at setup time instead (see below).

To publish a release, upload `dist/LocalTranscriber.zip` as a GitHub
release asset, e.g.:

```bash
gh release create v1.0.0 dist/LocalTranscriber.zip --title "v1.0.0" --notes "..."
```

## Setup (end users)

1. Download `LocalTranscriber.zip` from the
   [Releases](../../releases) page.
2. Extract it anywhere on a Windows machine (e.g. `C:\Tools\LocalTranscriber`).
3. That's it — no separate install step is required. The first time
   `transcribe.bat` is run (or `setup.bat` directly), it detects that
   `whisper-cli.exe`, `ffmpeg.exe`, and the speech model are missing and
   downloads them automatically into `bin\` and `models\` next to the
   scripts (~500 MB, one-time, needs internet). Every transcription after
   that runs fully offline.

## Run / Use

Drag a recording onto `transcribe.bat`:

```
Team Meeting.mp4  --(drag onto)-->  transcribe.bat
```

If dependencies aren't installed yet, `transcribe.bat` delegates to
`setup.bat` automatically before transcribing. Otherwise it produces
`Team Meeting.txt` next to the recording, and copies the transcript to
the clipboard (`Ctrl+V` to paste) when a single file was dropped.
Multiple files can be dropped at once; clipboard copy is skipped in that
case so the batch doesn't wait on you.

Supported inputs: `.mp4`, `.m4a`, `.mp3`, `.wav`, `.mov`, `.webm`, or
anything else ffmpeg can decode.

If a `.txt` already exists: dropping a single file asks whether to
overwrite it; dropping multiple files writes `Name.transcript.txt`
instead. The model used is `models\ggml-small.bin` — change the `MODEL`
line near the top of `transcribe.bat` to use a different one.

Full end-user documentation also ships inside the release zip as
`README.txt`.
