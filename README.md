# winsper — Local Windows Meeting Transcriber

A fully local, offline transcription utility for Windows. Drag a Zoom (or
any) recording onto `transcribe.bat` and get a `.txt` transcript next to
it, using [whisper.cpp](https://github.com/ggml-org/whisper.cpp) and
ffmpeg. No cloud APIs, no accounts, no network access at transcription
time.

See `specs/requirements.md` for the full spec this was built against.

## Repo layout

```
winsper/
├── src/               # source of truth for the shipped scripts
│   ├── transcribe.bat
│   └── README.md      # end-user docs, bundled into the release zip
├── scripts/
│   └── build.sh        # builds the release zip (run this, not the src/ files directly)
├── dist/                # build output — gitignored, regenerated by build.sh
└── .build-cache/         # downloaded whisper.cpp/ffmpeg/model files — gitignored
```

`src/transcribe.bat` on its own isn't runnable — it expects
`bin\whisper-cli.exe`, `bin\ffmpeg.exe`, and `models\ggml-small.bin` next
to it. `scripts/build.sh` assembles those into a complete folder and zips
it. Always edit `src/`, never edit inside `dist/`.

## Build / Release

Requires `curl`, `unzip`, and `zip` (all standard on macOS/Linux).

```bash
./scripts/build.sh
```

This downloads whisper.cpp (Windows CPU build), a static ffmpeg.exe, and
the `ggml-small.bin` model — caching each in `.build-cache/` so re-runs
are fast and skip anything already downloaded — then assembles everything
with `src/transcribe.bat` and `src/README.md` into
`dist/LocalTranscriber/`, and zips it to:

```
dist/LocalTranscriber.zip
```

To force fresh downloads (e.g. to pick up a newer whisper.cpp release),
delete `.build-cache/` first.

To publish a release, upload `dist/LocalTranscriber.zip` as a GitHub
release asset, e.g.:

```bash
gh release create v1.0.0 dist/LocalTranscriber.zip --title "v1.0.0" --notes "..."
```

## Setup (end users)

1. Download `LocalTranscriber.zip` from the
   [Releases](../../releases) page.
2. Extract it anywhere on a Windows machine (e.g. `C:\Tools\LocalTranscriber`).
3. Nothing else to install — `whisper-cli.exe`, `ffmpeg.exe`, and the
   model are already bundled inside.

## Run / Use

Drag a recording onto `transcribe.bat`:

```
Team Meeting.mp4  --(drag onto)-->  transcribe.bat
```

This produces `Team Meeting.txt` next to the recording, and copies the
transcript to the clipboard (`Ctrl+V` to paste) when a single file was
dropped. Multiple files can be dropped at once; clipboard copy is skipped
in that case so the batch doesn't wait on you.

Supported inputs: `.mp4`, `.m4a`, `.mp3`, `.wav`, `.mov`, `.webm`, or
anything else ffmpeg can decode.

If a `.txt` already exists: dropping a single file asks whether to
overwrite it; dropping multiple files writes `Name.transcript.txt`
instead. The model used is `models\ggml-small.bin` — change the `MODEL`
line near the top of `transcribe.bat` to use a different one.

Full end-user documentation also ships inside the release zip as
`README.md`.
